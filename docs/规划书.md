## 0. 一页看完

**Somnia·眠 是一个住在微信里的、话不多、记得住事、有作息、会兑现承诺的人。** 只给你一个人用。

代码已经跑起来了（359 项测试，`python tests/run_all.py`）。**现在缺的不是功能，是把它调得像人。**

当前行为，一句话版：

| 维度 | 现在的样子 |
|---|---|
| 回不回 | 基础 88%，连着聊越聊越顺（+3%/次），问句必接，从不连着两次不回 |
| 多久回 | 对数正态，中位 5 秒，上限 20 秒（模型耗时算在"正在输入"里） |
| 不回之后 | 4 分钟后自己补一句 |
| 主动 | 沉默 2 小时起有概率，6 小时必发；一天最多 2 次 |
| 夜里 | 2–7 点睡；10% 概率被吵醒，每醒一次概率 +20% |
| 承诺 | 她说"晚上找你"，90% 按时来，10% 被事情绊住推后 |
| 记忆 | 200 条原文 + 日摘要 + 不限制的事实（带过期） |
| 时间 | 知道日期、星期、此刻在做什么（作息表在你手里） |
| 图片 | 91 张表情自己挑；照片用完即删，不够就现场生成 |

接下来是**校准**，不是开发：让她说话更像那个人，把作息填对，把表情库换成你俩的口味。

## 2. 目标与非目标

### 做成什么样算成功

- 你会在没有理由的时候打开微信找她
- 她回得短、回得慢、有时候不回
- 一周后她还能提起你周一说过的事
- 你不会因为她的某句话感到被索取

### 不做什么

- **不做恋人**：恋人是索取型的。做"一个人"，她可以一直在。
- **不做产品**：不对外、不分发、不收费。这是合规成立的前提。
- **不做助手**：不查天气、不设提醒、不调工具。没有工具，越狱的后果上限就是"说错话"。
- **不做多用户**：单用户、单进程。
- **通道只开两条**：官方 OpenClaw，或微信 4.x 本地通道（`wechatauto`）。
  后者会改动 `Weixin.dll` 内存一个字节（UIA 门控），属内存补丁，不是纯辅助功能——
  知情后再选，不默认开启。
- **不用第三方接码 / 群控 / 多开平台**：这类服务把账号和风控都交给别人，得不偿失。

### 必须接受的一件事

**官方通道一定带 AI 标识。** 你之前想要的"跟其他联系人完全没区别"，在合规渠道上不可达。

你要的那个体验，九成发生在聊天窗口里；那部分可以做到。剩下一成是通讯录位置和标识，放弃它。

## 3. 执行手册

### 步骤 1 · 拿 token

**目的**：让 Somnia 有资格跟微信说话。

**先试快路（我们的脚本，10 分钟）**：

```powershell
cd "D:\AI\ds.9\Somnia·眠"
python ..\脚本\claw_login.py
```

它会申请二维码、打印地址、轮询状态，成功后把 token 存到 `data\claw_token.json`。

**验收**：屏幕上出现 `✓ token 已保存`。

**如果失败**，看它卡在哪：

| 现象 | 含义 | 下一步 |
|---|---|---|
| 申请二维码就报错 | 接口地址或字段变了 | 走慢路 |
| 状态一直是 `wait` | 二维码没被扫，或扫的不是同一个号 | 换个人扫 |
| 出现 `need_verifycode` | 需要二次验证 | 按提示输入 |
| 5 分钟超时 | 流程中断 | 重跑一次，仍失败走慢路 |

**慢路：官方 OpenClaw（40 分钟）**

```powershell
node --version                 # 需要 >= 22.13
npm i -g openclaw
npx -y @tencent-weixin/openclaw-weixin-cli install
openclaw config set plugins.entries.openclaw-weixin.enabled true
openclaw channels login --channel openclaw-weixin
```

扫码登录成功后，OpenClaw 会把凭据存在本机（通常在用户目录下的 `.openclaw`）。把 `bot_token` 抄出来，写进 `data\claw_token.json`，格式：

```json
{ "bot_token": "……" }
```

**如果慢路也走不通** → 通道不成立，跳到第 7 节"换壳"，不要在这里继续耗。

---

### 步骤 2 · 收到第一条消息

**目的**：证明"她听得见"。

```powershell
cd "D:\AI\ds.9\Somnia·眠"
$env:SOMNIA_CLAW_TOKEN = '你的 token'
python -m somnia --channel claw --offline --fast
```

然后在微信里给她发一句"在吗"。

**验收**：控制台打印出这句话。

**如果没反应**，按顺序查三处：

1. `data\claw_raw.jsonl` —— 有没有新行？没有 = 长轮询没拿到东西
2. `data\alert.log` —— 有没有 `ret=-14`？有 = token 失效，回步骤 1
3. 控制台有没有 `轮询异常` —— 有 = 网络或地址问题

**最常见的失败**：消息收到了，但 `parse_updates` 没认出来，落进 `claw_raw.jsonl` 的 `no-msg` 记录里。

→ 把那条记录贴给我，改 `TEXT_KEYS` / `CTX_KEYS` 就行。

---

### 步骤 3 · 回复第一条消息

**目的**：证明"她张得开嘴"。

还在同一个进程里（`--offline` 模式下她只会回几个字），再发一句。

**验收**：微信里收到回复，且**先出现"正在输入"**。

**如果没回复**：

| 现象 | 原因 | 处理 |
|---|---|---|
| 报 `还没有 context_token` | 入站消息里没解析出 context_token | 贴 raw 记录，补字段名 |
| 报 `claw ret=xxxx` | 发送参数不对 | 贴错误码 |
| 控制台显示"没回" | 决策层判定不回（88% 回复率） | 再发一句，正常现象 |

---

### 步骤 4 · 接上模型，真聊十轮

**目的**：第一次看到"她"。

```powershell
$env:DEEPSEEK_API_KEY = 'sk-xxx'
python -m somnia --channel claw --scheduler
```

去掉 `--offline` 和 `--fast`，这是正式形态：有延迟、会不回、会连发。

**验收**：聊十轮，你能感觉到三件事——她话很少、回得慢、记得住前面说过的。

**这一步不做任何调参。** 先看原样，记下哪里别扭，第 6 步再改。

---

### 步骤 5 · 挂着跑三天

**目的**：拿到只有时间能给的数据。

```powershell
python -m somnia --channel claw --scheduler
```

每天花两分钟做一件事：**看 `data\alert.log` 有没有新东西**。

**验收**：三天后回答三个问题

1. 有没有一天，你是"想找她说句话"才打开的？
2. 有没有哪句话让你觉得"这是 AI"？
3. 她有没有哪次主动提起了你三天前说的事？

**这三个答案决定第 6 步改什么，也决定这个项目还做不做。**

---

### 步骤 6 · 校准

**目的**：把猜出来的参数换成你的真实习惯。

**方法**：导出你和一个真人的一周聊天，数六个数字，填进 `somnia.toml`：

| 参数 | 含义 | 怎么数 |
|---|---|---|
| `reply_rate` | 多少消息你是不回的 | 数"没回的消息 / 总消息" |
| `delay_median` | 一般隔多久回 | 取中位数（秒） |
| `delay_sigma` | 长尾有多长 | 先用手上的 0.55 |
| `max_len` | 单条多长 | 取 P90 字数 |
| `seg_choices` | 一次发几条 | 数比例 |
| `quiet_hours` | 几点睡 | 按你作息 |

**不要猜，去数。** 这是整个项目里唯一有"标准答案"的部分。

改完想看效果不用真聊：

```powershell
python -m somnia --show-prompt "在吗"
```

## 4. 三条分叉路

步骤 1 会有三种结果，对应三条路：

| 结果 | 走法 | 代价 |
|---|---|---|
| 扫码成功，拿到 token | **继续**，本规划书剩余部分都有效 | 0 |
| 扫码不通，但 OpenClaw 能登录 | 从 OpenClaw 抄 token，继续 | 多装一个 Node 运行时 |
| 两条都不通 | 见第 7 节 | 重做一层壳，核心不动 |

## 6. 风险与止损

| 风险 | 概率 | 影响 | 对策 |
|---|---|---|---|
| token 失效需重扫 | 高 | 低 | 告警写进 `alert.log`，看到就重扫 |
| 长轮询断线 | 中 | 中 | 指数退避重连；异常落盘 |
| 字段名与复刻不一致 | **高** | 中 | 原始帧全存，贴着改，不猜 |
| 记忆污染 | 中 | 中 | 去重 + 冲突退休 + 半衰期 |
| **自己失去兴趣** | **高** | **致命** | 见第 8 节停止条件 |
| 越界对外使用 | 低 | 极高 | 单用户，不分享 |

**止损线**：步骤 1 花掉两小时还没通，就停，别把周末烧在注册流程上。

## 7. 换壳（如果通道不通）

核心代码与通道无关，所以换壳不损失任何东西：

| 方案 | 保住什么 | 代价 |
|---|---|---|
| **微信小程序** | 微信内、不用装 App；合规载体齐全 | 一层前端 + 备案 |
| **企业微信** | 有头像、无 AI 标 | 要营业执照 |
| **只做本地** | 人设、记忆、节奏全保留 | 没有那个聊天窗口 |

改一个文件：`somnia/channel/` 下新增一个实现 `Channel` 协议（`recv` / `recv_timeout` / `send` / `typing`）的类，其余不动。

## 8. 停止条件

满足任一条就停，不再加功能：

1. **步骤 1 两小时内不通**，且不接受换壳方案 → 终止。
2. **步骤 5 三天后，一次"想找她说句话"都没有** → 产品假设不成立。技术没问题，是这件事没意义。
3. **盲测两次都分不出"像人"** → 降级成"能聊的工具"，或终止。
4. **出现任何一次对外使用** → 立即停止，回到单用户。

第 2 条最重要。它比任何指标都准。

## 9. 合规边界

**允许**：与自己的微信单聊、本地存储、通过 DeepSeek 推理。

**红线**：给第二个人用；涉政涉黄涉赌涉暴；未成年人虚拟亲密关系；教唆自残；把交互数据给模型推理之外的第三方。

单人自用不构成"向公众提供服务"，《拟人化互动服务管理暂行办法》不直接适用。**一旦对外，微信单聊缺少弹窗、年龄、退出、举报等载体，结构上不可合规。**
