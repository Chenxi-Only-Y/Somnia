# 从零开始：把 Somnia·眠 跑起来

这份是**保姆级**的。假设你从没装过 Python、也没申请过 API，照着做就行。

> 已经会装 Python、手上有 API Key 的，可以直接跳到 **第四节**，五分钟能跑起来。

全程大概 40 分钟：

| 步骤 | 花多久 | 干什么 |
|---|---|---|
| 1 | 10 分钟 | 装 Python |
| 2 | 10 分钟 | 申请 API Key（要花一点钱） |
| 3 | 2 分钟 | 解压 |
| 4 | 1 分钟 | 启动 |
| 5 | 5 分钟 | 填设置、唤醒 |
| 6 | 10 分钟 | 给她写性格（可选，但强烈建议） |
| 7 | 随时 | 日常使用 |
| 8 | 30 分钟 | 接微信（可选） |

## 零、要下载的东西（链接都在这）

| 要什么 | 在哪下 | 什么时候要 |
|---|---|---|
| **Python 3.12** | <https://www.python.org/downloads/windows/> | 必须。找 **Windows installer (64-bit)** |
| **DeepSeek 开放平台** | <https://platform.deepseek.com> | 必须。注册 → 充值 → 创建 API Key |

除了 Python、7-Zip 和驱动包，其他都是网页打开就能用，不用下载安装。

还有一样：**项目本体** —— 就是别人给你的那个 `Somnia·眠` 压缩包，解压到你能记住的地方就行。

## 一、你需要准备什么

| 项目 | 说明 |
|---|---|
| 一台 Windows 电脑 | Win10 / Win11 都行。苹果电脑也能跑，但接微信必须是 Windows |
| 能上网 | 装软件、调模型都要 |

## 二、装 Python（约 10 分钟）

### 1. 打开官网

浏览器输入：**https://www.python.org/downloads/**

### 2. 下载

页面中间有个黄色大按钮写着 **Download Python 3.12.x**（版本号可能更新，3.11 以上都行）。
点它，会下载一个 `python-3.12.x-amd64.exe`。

### 3. 安装

双击刚下载的文件，第一个界面：

> ⚠️ **最下面有个勾选框：「Add python.exe to PATH」—— 一定要勾上。**
> 这是新手最容易漏的一步。不勾的话，后面双击 `start.bat` 会一闪就消失。

勾好之后，点上面的 **Install Now**，等进度条走完，点 Close。

### 4. 验证装好了

1. 按住键盘 **Win 键 + R**，弹出「运行」小窗
2. 输入 `cmd`，回车
3. 出现一个黑窗口，输入：

```
python --version
```

4. 回车。应该显示：

```
Python 3.12.7
```

**结果对照：**

| 你看到的 | 说明 |
|---|---|
| `Python 3.12.x`（3.11 以上） | ✅ 装好了，继续下一步 |
| `Python 3.10.x` 或更低 | ❌ 版本太老，回第 2 步下载 3.12 |
| `'python' 不是内部或外部命令` | ❌ 第 3 步的 PATH 没勾，重装一次 |
| 弹出了「应用商店」 | ❌ 同上，重装，记得勾 PATH |

## 三、申请 API Key（约 10 分钟）

模型不是白用的，需要一把「钥匙」。下面以 **DeepSeek** 为例，因为它便宜、中文好、接口简单。

> 开放平台地址：<https://platform.deepseek.com>（手机号注册）

### 1. 注册

浏览器打开：**https://platform.deepseek.com**

用手机号注册，登录。

### 2. 充一点钱

登录后，左侧菜单找 **「充值」**（或「余额 / 费用」），充一点点就行。
具体最低金额以页面为准，几十块够聊很久。

> 不充钱会怎样：程序能跑，但你一发消息就报「余额不足」，她不会回。

### 3. 创建 Key

左侧菜单 → **「API keys」** → 点 **「创建 API key」** → 随便起个名字（比如 `somnia`）→ 创建。

屏幕上会出现一串 `sk-` 开头的东西。形状大概是这样：

```
sk-XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX
```

> **上面这是假的，不是你的。** 你的那串是每次新建时随机生成的字母数字，
> 不会和示例一样 —— 看到这一行时，去点页面上的「复制」按钮，别手抄。
>
> ⚠️ **这串东西只完整显示这一次。** 关掉页面就看不到了，先粘贴到记事本存着。
> 如果忘了，删掉重新创建一个就行。

### 4. 记下三样东西

| 要填的 | 值 |
|---|---|
| 接口地址 | `https://api.deepseek.com/chat/completions` |
| 模型名 | `deepseek-flash` | 官方目前在用这个名字；填错会报 model 不存在 |
| API Key | `sk-` 开头那一长串（你自己的） |

### 5. ⚠️ 关于安全

**API Key 等于你的钱包。** 别人拿到就能花你的钱。

- 不要发到群里、不要截图发给朋友
- 不要粘贴到网上任何「在线测试」网站
- 本项目把它存在 `data/settings.json`，这个文件别随便发给别人

### 想换成别家的模型？

只要对方是 **OpenAI 兼容接口**，都能用。改两处：接口地址、模型名。

| 服务 | 接口地址 | 模型名 |
|---|---|---|
| DeepSeek | `https://api.deepseek.com/chat/completions` | `deepseek-flash`（快、便宜，本项目一直在用） |
| DeepSeek（想让它慢慢想） | 同上 | `deepseek-reasoner` |
| 月之暗面 Kimi | `https://api.moonshot.cn/v1/chat/completions` | 见 <https://platform.moonshot.cn> 的模型页 |
| 本地 Ollama（[下载](https://ollama.com/download)） | `http://127.0.0.1:11434/v1/chat/completions` | 你 `ollama pull` 的那个名字 |

> ⚠️ **模型名换得比软件快。** 上面的名字随时可能变，填之前去服务商的
> 「模型 / 文档」页复制一遍最保险。填错会报「模型不存在」，不会扣钱。

## 四、解压项目（2 分钟）

1. 找到压缩包，右键 → **「全部解压」**（别直接在压缩包里双击运行）
2. 解压到 `D:\Somnia·眠` 这种地方

> 路径注意：**别放桌面、别放「下载」里、别放微信文件夹**。路径也别太深
> （`D:\a\b\c\d\e\Somnia` 这种容易出怪问题）。`D:\Somnia·眠` 就很好。

3. 打开文件夹，应该看到这些东西：

```
Somnia·眠\
├── start.bat          ← 双击这个启动
├── stop.bat           ← 停止
├── restart.bat        ← 改完东西重启
├── clean.bat          ← 清理（打包给别人前用）
├── somnia.toml        ← 行为参数（回复频率、延迟、作息…）
├── persona\           ← 人设：SOUL.md + 模板
├── stickers\          ← 91 张表情包 + 备注
├── somnia\            ← 代码
├── tests\             ← 测试
└── docs\              ← 你正在看的文档
```

## 五、启动（1 分钟）

**双击 `start.bat`。**

会弹出两样东西：

1. **一个黑色窗口** —— 这是程序本体，**别关**。关了就等于停止。
2. **浏览器自动打开** `http://127.0.0.1:8765` —— 这是控制台

黑窗口里会显示：

```
  ta 不是人 · 这里的每一句都是算出来的 · 别投入真感情

Somnia·眠 控制台：http://127.0.0.1:8765
（未自动启动：先在页面上填好模型密钥和通道，再点「唤醒」）
```

**浏览器没自动打开？** 自己开浏览器，地址栏输入 `127.0.0.1:8765` 回车。

**第一次启动什么都不发生，这是对的。** 因为还没填密钥、也没定对象。

## 六、填三样，然后唤醒（5 分钟）

在浏览器里点左侧 **「设置」**。

### 需要填的

| 位置 | 填什么 | 说明 |
|---|---|---|
| **名字** | 留空，或写「眠」 | 留空就在终端显示 `ta`。名字不影响她说话 |
| **接口地址** | `https://api.deepseek.com/chat/completions` | 第三节记下的 |
| **API Key** | 你复制到记事本的那串 | 第三节复制的。**保存后只显示掩码，看不到原文** |
| **模型名** | `deepseek-flash` | 同上 |
| **收发方式** | 选 `cli（终端里先试试）` | **第一次必须先选这个**，不用装任何东西 |

其他先都别动：

- 「允许 ta 主动开口」—— 等她能说话了再说，先关着
- 「聊天对象」「wxid」—— 接微信才用，现在不用管

### 然后点左下角的「唤醒」

黑窗口里会出现：

```
—— 眠 ——（cli，Ctrl-C 退出）

你: 
```

**在黑窗口里打字**，回车发出去：

```
你: 在吗
眠: 在
```

如果她回你了 —— **成功了。** 环境、Key、模型全通了。

如果没回或者报错，跳到 **[第十节：出问题怎么办](#十出问题怎么办)**。

## 七、给她写性格（10 分钟，强烈建议）

出厂状态**没有性格**。她现在只是一个「说话很短的人」，说不出什么味道来。

### 第一步：决定怎么改

**方式 A：在面板里点**

左侧 **「ta 是谁」**，有十几个卡片：身份、关系、对方、说话方式、状态、黏人与边界、不做什么、示例……

每张卡片上面有一行灰字提示，照着写。写完点保存。

**方式 B：改文件**

把 `persona\persona.example.md` **复制一份**，改名成 `persona.md`，用记事本打开写。

> 以 `>` 开头的行是提示，不会发给模型。写错格式不要紧，随便写。

### 第二步：⚠️ 一定要做的一步

回到 **「设置」** 页，勾上：

```
☑ 人设参与对话
```

**不勾的话，你上面写的一切都不会影响她怎么说话**，只是存在那儿。
这是本项目最容易误解的地方，写在这里免得你白写半天。

### 第三步：随便写几句就行

不用写得很完整。举个例子（填在「身份」里）：

```
27 岁，在厦门开一家小花店，早上要去进货
说话不急，偶尔懒，不太会安慰人但会在旁边待着
```

填完点保存，然后回黑窗口发一句试试，感觉不对再改 —— 改完不用重启，下一句就生效。

## 八、日常怎么用

### 面板五个页面

| 页面 | 看什么 |
|---|---|
| **回忆** | 你们聊过的全部。按天分组，顶部可以按日期筛选；可以勾选删除 |
| **此刻** | 她「为什么回 / 为什么没回」的决定记录。她半天不理你时，来这儿看 |
| **图册** | 表情包和照片。可以上传、改备注、删除 |
| **ta 是谁** | 人设，按块编辑 |
| **设置** | 密钥、通道、主动性、清空记忆 |

### 左下角的两个按钮

- **唤醒** —— 开始收发消息
- **睡下** —— 停止。**睡了就不会再回任何消息**，包括主动找你

### 怎么关掉

- 点「睡下」→ 程序还在，只是不说话了
- 直接关黑窗口 → 程序完全退出

### 想清空重来

设置页最下面 → **「清空所有记忆」**。对话、事实、摘要、承诺都会删掉，
**会先自动备份**到 `data\backup\`。人设和图片不受影响。

## 九、接微信（可选，30 分钟）

不接微信也能用（就在黑窗口聊），但接上之后她才真的「住在微信里」。

### 0. 先确认微信是 4.x

下载地址：<https://pc.weixin.qq.com/>（官方）。
装好后点左上角头像看版本，**低于 4 的读不到界面**，先去升级。

### 1. 装驱动包

驱动包主页（可以先看看说明）：<https://pypi.org/project/wechatauto-replica/>

在项目文件夹里，**空白处按 Shift + 右键** → 「在此处打开 PowerShell 窗口」，输入：

```
pip install wechatauto-replica
```

等它装完（会顺带装好几个包，几分钟）。

> 装不上？换成 `python -m pip install wechatauto-replica`。
> 报「网络超时」就再试一次，或者换手机热点。

### 2. 微信要求

- 电脑版微信 **4.x**（不是 3.9 那种老版）
- 登录好，**窗口要露在外面，别最小化到托盘**

### 3. 找三个 wxid

打开微信的文件目录（默认在 `D:\微信\xwechat_files\`），会看到几个文件夹，名字长这样：

```
wxid_abc123def456_2a90      ← 这是你的账号（发送账号）
wxid_xyz789uvw012_42fd      ← 可能是对方的
```

**wxid 就是去掉最后下划线后缀的那部分**，比如 `wxid_abc123def456`。

> 不确定哪个是对方的？在微信里点开他的资料页看微信号；
> 或者看文件夹的修改时间，正在聊的那个就是最近改过的。

### 4. 在设置页填

| 框 | 例子 | 说明 |
|---|---|---|
| 收发方式 | `wechatauto` | 换成这个 |
| 聊天对象（显示名） | `小明` | 对方微信昵称，用来让窗口搜索 |
| 对象 wxid | `wxid_xyz789uvw012` | 对方的 |
| 发送账号 wxid | `wxid_abc123def456` | 你自己的 |

填完点「唤醒」。

### 5. ⚠️ 代价：先看完再决定

这个驱动包做的事，微信**没有授权**：

- 往微信进程的**内存**里写 1 个字节，把无障碍开关打开（不然读不到界面）
- 读你本地 `xwechat_files` 里的聊天数据库
- 用模拟点击 / 粘贴的方式，替你点发送

**可能发生的事**（按概率从高到低）：

| 情况 | 说明 | 严重程度 |
|---|---|---|
| **微信被意外登出** | 最常见。手机或电脑会被踢下线，重新扫码登录即可，**聊天记录不会丢** | 麻烦，但可恢复 |
| 消息发重 / 发错对象 | 窗口焦点被别的程序抢走时可能发生 | 尴尬 |
| 账号被限制或封禁 | 概率低，但不是零 | 严重 |

**所以：**

- **先用小号或备用号跑几天**，确认稳定了再换主号
- 别在挂着重要客户、工作群的号上跑
- 出问题按这个顺序处理：
  1. 面板点「睡下」（先让它停下来）
  2. 关掉微信窗口，重新登录
  3. 反复出现就 `pip uninstall wechatauto-replica`，回到 `cli` 通道
- 微信重启后内存补丁自动复原，**不会损坏文件、不会丢聊天记录**

**你现在有能力撤销这件事** —— 确认了解了再往下填 wxid。

## 九点五、怎么更新到新版本

更新**不会动你的东西** —— 对话、记忆、人设、表情包、照片都在。

**如果面板左下角出现「↓ 新版本」**

说明作者发了新版。点一下 → 看它说改了什么 → 确认 → 自动下载覆盖。
更新完**关掉黑窗口，重新双击 `start.bat`** 才生效。

**如果没出现那个按钮**

作者可能没配自动更新。那就用 `update.bat`：

1. 把新版 zip 下载下来（作者会发给你）
2. 双击项目里的 `update.bat`
3. 把 zip 拖进黑窗口，回车
4. 看到"完成"就行，重新 `start.bat`

更新前它会自动把数据库和设置备份到 `data\backup\pre_update_时间\`，出问题能找回。

## 十、出问题怎么办

先看**黑窗口**里的报错，那是第一手信息。
再看 `data\alert.log`（用记事本打开），发送失败、模型报错都记在这儿。

| 症状 | 原因 | 怎么办 |
|---|---|---|
| 双击 `start.bat`，黑窗口一闪就没 | Python 没装或没勾 PATH | 回第二节重装，**勾上 Add python.exe to PATH** |
| 提示「需要 Python 3.11 以上」 | 版本太老 | 装 3.12 |
| 浏览器打不开 `127.0.0.1:8765` | 没启动成功 / 端口被占 | 看黑窗口报错；先双击 `stop.bat` 再 `start.bat` |
| 提示「端口 8765 已被占用」 | 已经有一个在跑了 | 直接开浏览器访问，不用再启动 |
| 点「唤醒」报错 | 通道选错、Key 没填 | 检查收发方式是不是 `cli`，Key 是不是 `sk-` 开头 |
| 提示「cli 通道要终端输入，但这个面板没有控制台」 | 不是用 `start.bat` 起的，没有黑窗口可输入 | 关掉，改双击 `start.bat` |
| 她完全不说话 | 模型报错 / 余额不足 | 看 `data\alert.log`；去平台充钱 |
| 报「模型不存在 / model not found」 | 模型名填错或已下线 | 去服务商控制台复制当前的模型名 |
| 她只回一两个字 | **正常**，设定就是这样 | 想长一点就在人设里写「说话可以长一点」 |
| 人设写了没效果 | 「人设参与对话」没勾 | 设置页勾上 |
| 中文显示成乱码 | 黑窗口编码问题 | 无视，不影响功能 |
| 杀毒软件报警 | 程序要控制微信窗口 | 允许/信任，否则接不了微信 |
| 微信收不到消息 | 窗口最小化了 | 把微信窗口露出来，别收进托盘 |
| 改 `somnia.toml` 没反应 | 面板设置会盖住文件 | 优先级：环境变量 > 面板 > toml > 代码默认 |
| 想看她的完整提示词 | —— | 黑窗口里 `python -m somnia --show-prompt "在吗"` |

## 十一、名词小抄

| 词 | 什么意思 |
|---|---|
| **API Key** | 一串密码，证明「花的钱是你的」 |
| **接口地址** | 去哪台服务器请求回答 |
| **模型名** | 用哪个模型，同一个平台有好几个 |
| **终端 / 黑窗口 / cmd** | 那个黑底白字的窗口，打字回车能执行命令 |
| **端口** | 一个数字，程序在电脑里的「门牌号」，这里用 8765 |
| **wxid** | 微信内部给每个人分配的 ID，不是微信号 |
| **toml / json** | 配置文件格式，用记事本就能改 |
| **prompt** | 每一次请求前塞给模型的那段话，决定她是谁、记得什么 |

---

## 十二、花钱吗？安全吗？

**花钱**：只有调模型花钱，按字数算。聊天一天几毛到两块，看聊多少。
表情包、图片、面板、记忆都是本地跑的，不花钱。

**安全**：

- 所有对话、记忆、图片都存在你自己电脑的 `data\` 里，不上传
- 只有「发消息」那一刻，历史和你的话会发给模型服务商 —— 和用网页版 AI 一样
- 别把 `data\` 文件夹发给别人，里面有你的聊天记录和密钥
